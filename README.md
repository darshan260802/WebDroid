# WebDroid

Turn any website into an app on your Android phone, without installing anything else.

You paste a link and WebDroid gives that site:

- its own icon and colour on the WebDroid home screen (and, if you like, on your launcher);
- **its own card in Android's Recents**, with no address bar, tabs or progress bars;
- a **built-in uBlock Origin ad blocker** (uBO's real filtering engine and lists);
- a **native video player** that takes over page videos, with UC Browser-style gestures.

Download the latest APK from **[Releases](https://github.com/darshan260802/WebDroid/releases/latest)**.

## Features

### Web apps
- No browser chrome. A branded splash shows while the page loads, and system bars take the site's `theme-color`.
- **Gesture controls:** pull down at the top of a page to refresh. Keep pulling for the app menu (back, forward, home, share, copy link, open in browser, desktop site, ad blocker, video mode, settings). Long-press a link or image for link actions.
- Optional per-app **mini toolbar**: a small handle at the top that pulls down into a back / forward / reload / share bar.
- Each app is its own document task: it shows in Recents with its name, icon and colour, and keeps its state.
- **Separate login** per app (isolated cookies and storage via WebView profiles), so you can sign into two accounts of the same site.
- **Fingerprint / screen-lock app lock**, **desktop mode**, **force dark**, and a per-app setting to open other sites in your browser.
- Downloads (including `blob:`/`data:` files), file upload, and camera / microphone / location prompts. Sign-in pop-ups open in a sheet.
- **Add to home screen**: a launcher shortcut that opens the app inside WebDroid.

### Ad blocking: uBlock Origin inside the app
WebDroid embeds the [uBlock Origin](https://github.com/gorhill/uBlock) filtering engine. It is not a re-implementation.

- Every request the page makes goes through uBO's static network filtering engine (`@gorhill/ubo-core`), including `$redirect` surrogates.
- Cosmetic filtering runs uBO's own rules: element hiding, generic and specific filters, and procedural filters (`:has-text`, `:upward`, …).
- uBO **scriptlets** (`##+js(...)`) are injected before page scripts.
- The default lists match uBO's defaults: uBlock filters (ads, badware, privacy, unbreak, quick fixes), EasyList, EasyPrivacy, Peter Lowe and the URLhaus malware list. Annoyance and cookie-notice lists are optional.
- Lists refresh **in the background** every few days and are recompiled on the device. Filtering keeps working meanwhile.

How it works: [`tools/adblock`](tools/adblock/README.md).

### Native video player
When a page plays a video, WebDroid can open it in a native Media3 player. Each app chooses **Auto**, **Button** or **Off**.

- **Gestures:** swipe on the left for brightness, on the right for volume, horizontally to seek. Double-tap left or right to skip 10 s, pinch to zoom or fill, hold for 2× speed.
- Audio track, subtitle track and quality selection; playback speed from 0.25× to 3×; fit, zoom and stretch; rotation; a screen lock.
- **Picture-in-picture**, **background play** with media notification controls, **resume** where you left off, and **download** for direct MP4/WebM streams.
- Videos that can't be extracted (DRM, or YouTube-style MSE streams) play in the page. In fullscreen they still get the brightness, volume and seek gestures.

## Build

- Android Gradle Plugin 8.9, Kotlin 2.2, Jetpack Compose, Media3 and AndroidX WebKit.
- The ad-block assets are generated by `tools/adblock` (Node 20+):

```sh
cd tools/adblock && npm ci && node build.mjs && node test.mjs
cd ../.. && ./gradlew assembleRelease
```

GitHub Actions builds a signed APK on every push. Pushing a `v*` tag publishes a GitHub release. Release signing reads the `WEBDROID_KEYSTORE_B64` repository secret.
