# WebDroid 0.3.0: dark mode and automatic updates

## Dark mode
- WebDroid's screens, menus and sheets now come in a warm dark Clay theme.
- Choose **System**, **Light** or **Dark** in Settings → Appearance, or tap the sun/moon button on the Home screen.
- Websites still follow your phone's dark mode setting; use an app's "Force dark" switch to darken one.

## Automatic updates
- WebDroid checks this project's GitHub releases when you open it and twice a day.
- New versions download in the background on Wi-Fi (mobile data can be allowed in Settings → Updates).
- An "Update ready" card and notification appear; one tap opens Android's installer. Your apps, logins and settings are kept.
- Every download is checked against the release's SHA-256 and WebDroid's signing key before it's installed.
- The first update asks you to allow "Install unknown apps" for WebDroid.
