# WebDroid 0.5.1: a Tor exit country for each app

- Apps that use Tor can now each leave Tor in their own country: open an app's settings, choose **Tor**, then **Exit Country**. One app can appear in Germany while another appears in Japan, at the same time.
- **Default** follows Privacy → Tor → Default Exit Country; **Any** lets Tor choose.
- If a country has no suitable Tor exits, the app shows that instead of loading through another country.
- Changing an app's VPN or exit country takes effect for its open connections straight away.
- Re-opening an app no longer restarts the WireGuard tunnel other apps are using.
